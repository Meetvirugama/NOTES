## ⚡ One-Page Chapter Summary

### The Core Concept
*   **Unsupervised Learning:** Operates on data without labels ($y$). Used primarily when manual human labeling is too slow or expensive.
*   **Main Tasks:** Clustering (grouping similar data), Anomaly Detection (flagging outliers), and Density Estimation (estimating the underlying probability distribution of the data).

### K-Means Clustering
*   **How it works:** Hard-clustering distance algorithm. Expectation-Maximization step places $k$ centroids randomly, assigns points to the nearest centroid, then moves the centroid to the center of those points. Repeats until convergence.
*   **Drawbacks:** You MUST specify $k$. It only works on spherical clusters.
*   **K-Means++:** A smarter initialization step that prevents the algorithm from getting stuck in terrible local optimums by pushing initial centroids far apart.

### Evaluating Clusters
*   **Inertia (Elbow Method):** Mean squared distance to the closest centroid. It always goes down as $k$ goes up. Do not pick the minimum; plot it and pick the "Elbow" inflection point.
*   **Silhouette Score:** Measures cohesion vs separation. Scales from -1 to +1. You can safely pick the highest score. Plotted as Silhouette Diagrams (knife shapes).

### Advanced Clustering Uses
*   **Preprocessing:** Run K-Means, and use the distances to centroids as new features for a classifier. You can use `GridSearchCV` to find the exact perfect $k$.
*   **Label Propagation (Semi-Supervised):** Run K-Means to find $k$ clusters on a massive unlabeled dataset. Manually label the $k$ representative centroids, then automatically propagate those labels to the core 20% of the clusters.

### DBSCAN
*   **How it works:** Pure Density-Based clustering. It draws an $\epsilon$-radius circle around a point. If it has `min_samples` neighbors, it's a Core Instance. Connected Core Instances form clusters of *any shape*.
*   **Anomalies:** Any isolated point is immediately flagged as an Anomaly (label `-1`).
*   **Drawbacks:** Fails if the dataset contains clusters of varying densities. Cannot `predict()` on new instances (must train a secondary classifier like KNN on the core instances).

### Gaussian Mixture Models (GMM)
*   **How it works:** Generative probabilistic model. Assumes data is generated by $k$ overlapping Gaussian (normal) distributions. Excellent at finding elongated, elliptical clusters.
*   **Anomaly Detection:** Calculates a Probability Density Function. If a point lands in an extremely low-density region (e.g., bottom 4%), it is flagged as an anomaly.
*   **Evaluation:** Cannot use Silhouette scores (penalizes ellipses). Must use theoretical information criteria (BIC or AIC) and pick the lowest value to find the optimal $k$.
